# OHLI Social v3.6.10 — Test Plan

## 1. Build APK
1. Upload seluruh isi ZIP ini ke repository atau unggah ZIP `OHLI-Social-Source-v3.6.10.zip` ke root repository sesuai workflow.
2. Jalankan GitHub Actions `Build OHLI Social Server APK`.
3. Pastikan log melewati `:app:compileDebugJavaWithJavac` dan mencapai `BUILD SUCCESSFUL`.
4. Unduh artifact `OHLI-Social-Server-APK`.

## 2. Validasi versi
- Periksa `versionName=3.6.10` dan `versionCode=39`.
- Periksa endpoint `/health` melaporkan `3.6.10`.

## 3. Validasi server dan fitur lama
- Nyalakan server pada perangkat Android.
- Pastikan alamat lokal tampil dan `/health` merespons.
- Tes login/daftar OTP dengan nomor uji yang dikendalikan sendiri.
- Tes chat, feed, Story, profil dan LIVE setelah server aktif.

## 4. Catatan
Perbaikan v3.6.10 ditujukan untuk mengatasi error Java `unclosed string literal` pada `MainActivity.java` baris 199–200 di build v3.6.9. Tes penuh kamera LIVE, OTP lintas perangkat, dan performa server bukan bagian dari bukti kompilasi ini.
