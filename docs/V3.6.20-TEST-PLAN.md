# OHLI Social v3.6.20 — Test Plan

## 1. Profile Story/Highlight
- Buka profil pada layar 320 px, 360 px, 390 px, dan tablet.
- Pastikan setiap cover Sorotan tampil bulat (width dan height sama), tidak oval, gambar ter-crop `cover`, dan judul tetap terbaca.
- Uji profil akun sendiri dan profil teman.

## 2. Video call (dua perangkat dan dua akun uji)
- Pastikan HTTPS dan izin kamera/mikrofon diberikan pada kedua perangkat.
- Mulai panggilan video dari Chat ke akun uji kedua.
- Pastikan overlay memenuhi viewport dan video remote mengisi layar.
- Pastikan preview lokal kecil di kanan atas.
- Ketuk preview lokal: tampilan lokal menjadi besar dan remote menjadi jendela kecil. Ketuk jendela kecil kembali untuk menukar.
- Uji mute/unmute, kamera on/off, ganti kamera depan/belakang, dan akhiri panggilan.
- Uji panggilan masuk, tolak, angkat, panggilan suara lalu beralih ke video.
- Pastikan menutup panggilan melepas semua track kamera/mikrofon dan mengembalikan overlay.
- Uji di Wi-Fi yang sama dan lintas jaringan. Bila ICE gagal, konfigurasi TURN relay harus disiapkan di luar source ini.

## 3. Performa
- Ukur startup service, endpoint `/`, feed, chat, dan penggunaan RAM pada perangkat yang sama sebelum/sesudah.
- Pastikan UI pengelola Android tetap responsif ketika file JSON besar dimuat.
- Pastikan server tidak menerima request sebelum `dataReady`.
- Simulasikan antrean worker penuh pada staging dan pastikan request berlebih mendapat HTTP 503 tanpa menghentikan accept loop.
- Pastikan pesan aktif tetap disinkronkan, notifikasi masuk tetap diperbarui, dan polling tidak bertumpuk ketika server lambat.
- Buka halaman Social dan pastikan Story, saran pengguna, trending dapat memuat bersamaan dengan feed tanpa error.

## 4. Regresi fitur
- Login/register/OTP, Chat teks/media, status, Story, postingan, komentar, like, follow, grup/channel, Live, upload, dan pengaturan.
- Jalankan `node tools/source-verify.mjs`.
- Jalankan `node tools/smoke-test.mjs` hanya dengan dua akun disposable yang memang disiapkan untuk tes.
- Build `gradle :app:assembleDebug` pada GitHub Actions atau lingkungan Android SDK.
