# OHLI Social v3.6.8 — Test Plan

## A. LIVE dua perangkat
1. Akun A membuka LIVE dari perangkat A melalui HTTPS.
2. Akun B membuka siaran A dari perangkat B sebagai penonton.
3. B menekan Minta bergabung; A menerima permintaan.
4. B memberi izin kamera dan mikrofon lalu mengaktifkannya.
5. Pastikan A melihat video B dan B tetap melihat video A. Pastikan audio dua arah terdengar tanpa feedback berlebihan.
6. Matikan kamera B: tile B di A harus menampilkan avatar; nyalakan lagi: video B kembali.
7. B keluar panggung: siaran A harus tetap berjalan.

## B. Navigasi Story
1. Buka OHLI Chat di lebar layar mobile: tab Status/Story harus terlihat dan dapat dibuka.
2. Buka OHLI Social: pintasan Story di bottom navigation mobile harus tersembunyi, tanpa mengubah menu Story lain atau fitur Story itu sendiri.

## C. Performa
1. Bandingkan request LIVE di DevTools sebelum/sesudah; polling utama sekarang 2,5 detik dan request signal/comment tak boleh overlap.
2. Catat waktu respons API /api/live/participants, /api/live/signals, /api/live/comments, dan /api/messages pada server lokal dan URL tunnel.
3. Tes minimal 2 akun dan ulangi melalui jaringan berbeda.

## Batas validasi
`node tools/source-verify.mjs` adalah pemeriksaan statis. Build APK dan uji runtime pada dua perangkat masih wajib. Jika host masih tidak menerima track setelah renegosiasi, periksa log signaling/ICE dan konfigurasi TURN.
