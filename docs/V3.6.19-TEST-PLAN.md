# OHLI Social v3.6.19 — Test Plan

## Build
1. Upload `OHLI-Social-Source-v3.6.19.zip` ke root repository.
2. Pastikan `.github/workflows/build-apk.yml` memakai workflow v3.6.19.
3. Jalankan Actions: `Build OHLI Social Server APK`.
4. Pastikan task `:app:compileDebugJavaWithJavac` lolos.
5. Pastikan artifact `OHLI-Social-Server-APK-v3.6.19` berisi `app-debug.apk`.

## Regression checks
- [ ] ServerService.java mengompilasi referensi `Set<String>`.
- [ ] ServerService.java mengompilasi `new HashSet<String>()`.
- [ ] Halaman feed/FYP dapat dibuka.
- [ ] Urutan rekomendasi masih memuat berdasarkan minat dan interaksi OHLI.
- [ ] Login, OTP, Story, Sorotan, Chat, LIVE, dan upload tidak berubah akibat patch import.

## Two-account smoke test
Jalankan `node tools/smoke-test.mjs` setelah mengisi environment:
- `OHLI_PHONE_A`
- `OHLI_TOKEN_A`
- `OHLI_PHONE_B`
- `OHLI_TOKEN_B`

Opsional untuk sesi perangkat kedua:
- `OHLI_TOKEN_A_DEVICE2`
- `OHLI_TOKEN_B_DEVICE2`
