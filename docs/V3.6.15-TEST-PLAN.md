# OHLI Social v3.6.15 — Build Test Plan

## Pemeriksaan source
- [ ] ZIP memiliki settings.gradle, build.gradle, gradle.properties, dan app/build.gradle pada root yang sama.
- [ ] settings.gradle menyertakan modul :app.
- [ ] Root build.gradle mendeklarasikan Android Gradle Plugin 8.7.3.
- [ ] Workflow memilih ZIP v3.6.15 atau menemukan proyek yang sudah diekstrak.
- [ ] Workflow memvalidasi root proyek sebelum menjalankan Gradle.

## GitHub Actions
1. Simpan OHLI-Social-Source-v3.6.15.zip di root repository, atau ekstrak seluruh isi source ke root.
2. Simpan workflow sebagai .github/workflows/build-apk.yml.
3. Jalankan Actions: Build OHLI Social Server APK.
4. Pastikan log menampilkan `Android project ditemukan di:` dan `Building from:` dengan folder yang berisi settings.gradle.
5. Pastikan task `:app:assembleDebug` berhasil.
6. Unduh artifact `OHLI-Social-Server-APK-v3.6.15`.

## Catatan
Build Gradle penuh harus dikonfirmasi oleh GitHub Actions; pemeriksaan lokal source/arsip tidak menggantikan build CI.
