# OHLI Social v3.6.21 — Uji sebelum publikasi

Lakukan tes menggunakan dua atau tiga akun percobaan. Jangan gunakan akun/data pengguna produksi sebagai target tes.

## 1. Backup dan upgrade

- [ ] Buat backup melalui panel server dan salin arsip keluar perangkat.
- [ ] Instal APK v3.6.21 di atas APK lama dengan applicationId yang sama.
- [ ] Verifikasi login, daftar akun, chat lama, postingan, komentar, Story, Sorotan, media dan pengaturan tetap tersedia.
- [ ] Pastikan tidak ada duplikasi atau kehilangan data setelah server dimulai ulang.

## 2. Kamera / video call 1:1

- [ ] Jalankan panggilan dari HP A ke HP B pada jaringan Wi-Fi yang sama.
- [ ] Pastikan video teman memenuhi layar dan preview diri berbentuk lingkaran/jendela kecil sesuai desain.
- [ ] Ketuk preview diri beberapa kali; posisi video utama dan preview harus saling bertukar.
- [ ] Ganti kamera depan ke belakang dan kembali lagi di kedua perangkat.
- [ ] Pastikan video tetap terlihat pada kedua perangkat setelah pergantian; uji juga saat izin kamera ditolak atau kamera sedang digunakan aplikasi lain.
- [ ] Matikan/nyalakan kamera, mute/unmute mikrofon, akhiri panggilan, lalu periksa catatan panggilan.
- [ ] Ulangi di jaringan berbeda. Jika koneksi gagal pada jaringan tertentu, evaluasi konfigurasi STUN/TURN.

## 3. LIVE

- [ ] Mulai LIVE dari HP A, gabung sebagai peserta dari HP B.
- [ ] Uji ganti kamera pada Host dan peserta.
- [ ] Pastikan video setiap pihak tetap terlihat; uji keluar/masuk peserta dan kamera mati/hidup.
- [ ] Uji pada dua jaringan berbeda; perhatikan bahwa WebRTC P2P dapat gagal pada NAT tertentu tanpa TURN.

## 4. Riwayat tontonan

- [ ] Tonton beberapa video/postingan dengan akun A.
- [ ] Buka Pengaturan > History/Riwayat dan verifikasi thumbnail kotak 1:1, tanggal, serta urutan.
- [ ] Ketuk konten untuk membuka ulang.
- [ ] Hapus satu konten atau cabut izin konten, lalu pastikan riwayat tidak membocorkan media privat.

## 5. Riwayat panggilan

- [ ] Buat panggilan audio dan video yang dijawab.
- [ ] Buat panggilan tak terjawab dan panggilan ditolak.
- [ ] Pastikan riwayat menampilkan jenis, arah, tanggal/waktu, status, dan durasi setelah tersambung.
- [ ] Buka akun yang sama di perangkat lain dan pastikan catatan tersinkron melalui host yang sama.
- [ ] Hapus riwayat akun A dan pastikan riwayat akun B tidak ikut terhapus.

## 6. Panel admin dan notifikasi

- [ ] Buat akun tes baru; periksa notifikasi login/registrasi dan alur OTP.
- [ ] Periksa apakah status online berubah saat akun aktif dan menjadi offline setelah logout/masa tidak aktif.
- [ ] Uji suspend sementara pada akun tes; pastikan sesi lama dicabut.
- [ ] Uji nonaktifkan, soft-delete, dan pulihkan pada akun tes; verifikasi data tidak dihapus permanen.
- [ ] Pastikan akun non-admin tidak bisa membuka aksi moderasi melalui API.

## 7. Server 24 jam dan jaringan

- [ ] Aktifkan server dan foreground notification.
- [ ] Nonaktifkan optimasi baterai OHLI melalui pengaturan Android, sambungkan charger, dan aktifkan auto-start OEM bila tersedia.
- [ ] Matikan layar minimal 30–60 menit; akses server dari perangkat kedua secara berkala.
- [ ] Restart Android dan pastikan server mencoba mulai kembali bila fitur server sebelumnya diaktifkan.
- [ ] Matikan Wi-Fi tetapi pertahankan data seluler; pastikan status layanan dan alamat lokal berubah sesuai jaringan.
- [ ] Matikan seluruh akses internet: data lokal tetap berada di penyimpanan perangkat, tetapi akses dari internet harus gagal sampai koneksi kembali.
- [ ] Nyalakan internet kembali dan pastikan tunnel eksternal yang dikelola terhubung ulang.
- [ ] Jangan menilai tunnel aktif hanya karena URL tersimpan di panel. Periksa proses cloudflared dan uji link dari jaringan eksternal.
